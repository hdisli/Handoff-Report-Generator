# START HERE — Swarm Einstiegspunkt

Wenn Hasan „Schwarm“ sagt, **immer zuerst diese Datei lesen**.

## Kanonische Quelle (Single Source of Truth)
1. `swarm/SWARM_ALL_IN_ONE.md`  ← Primärdatei
2. `swarm/SWARM_MASTER_PROMPTS.md` ← Rollen-Prompts
3. `swarm/SWARM_BLUEPRINT_V2.1.md` ← Blueprint/Strategie
4. `swarm/SWARM_COMMANDS.md` ← Kurzbefehle

## Standard-Protokoll bei jedem Neustart/Reset
1. `swarm/START_HERE.md` lesen
2. `swarm/SWARM_ALL_IN_ONE.md` laden
3. Mit `STATUS | scope=all` starten
4. Danach entweder:
   - `RUN_BATCH ...` (neue Produktion)
   - `ANALYZE ...` (Auswertung)
   - `REWORK ...` (Überarbeitung)

## Trigger-Wörter
